# デザイン設計書 (DESIGN.md)

## 1. デザインコンセプト

- **"Clean & Focused"**: 翻訳作業を妨げない、シンプルで洗練されたインターフェース。
- **"Premium & Smart"**: Vanilla CSS を駆使した微細なグラデーション、滑らかなアニメーション、モダンなタイポグラフィによる高級感の演出。装飾を削ぎ落とした「スマートな道具」としての佇まい。
- **"Responsive"**: PC・タブレット・スマートフォンの全デバイスで快適に利用可能。

## 2. レイアウト構成

### レイアウト案 (Ultra Minimal Mock)

```text
+-------------------------------------------------------------+
| Nani-clone                                          [ (o) ] | <- Header
+-------------------------------------------------------------+
|                                                             |
|                                                             |
|      +-----------------------+     +-----------------------+|
|      | Japanese          [<>]|     | English           [#] ||
|      |-----------------------|     |-----------------------||
|      |                       |     |                       ||
|      | [ 翻訳するテキスト ]  |     | [ 翻訳結果 ]          || <- Area
|      |                       |     |                       ||
|      |                       |     |                       ||
|      |-----------------------|     |-----------------------||
|      | [ 0 / 5,000 ]         |     | [ Gemini 1.5 Flash ]  ||
|      +-----------------------+     +-----------------------+|
|                                                             |
|                                                             |
+-------------------------------------------------------------+
| Your data is never saved on our servers.                    | <- Footer
+-------------------------------------------------------------+
```

### 構成詳細

1. **Header**:
   - 控えめなロゴ（テキストのみ）と設定ボタン。
2. **Translation Content Area (Main)**:
   - 画面中央に配置。入出力カードを左右（モバイルは上下）に整列。
   - **Source Area (入力)**: 余計な装飾を一切排除したシームレスなテキストエリア。
   - **Target Area (出力)**: 翻訳結果が静かに表示される。
3. **Footer**:
   - サービス方針を示すシンプルな一行。

## 3. カラースキーム & コンポーネント

### カラーパレット (例)

- **Primary**: `hsl(250, 60%, 50%)` (Deep Indigo) - アクションボタン用。
- **Background**: `hsl(0, 0%, 98%)` / Dark: `hsl(240, 10%, 4%)`
- **Surface**: Glassmorphism (`backdrop-filter`) を活用したカードデザイン。

### 主要コンポーネント (Vanilla CSS)

- **Interaction**:
  - `textarea`: フォーカス時のソフトな発光エフェクト。
  - `button`: ホバー時のスケールアップ、クリック時の押し込み感。
- **Feedback**:
  - 翻訳中: 指向性のあるプログレスバー、またはスケルトンアニメーション。
  - コピー成功: トースト通知（スッと出て消える）。

## 4. フロントエンド設計 (Next.js)

### 状態管理

- **React Context / hooks**:
  - `useTranslation`: 入力テキスト、翻訳結果、言語ペア、モデル（Gemini 1.5 Flash）の管理。
  - `useApiKey`: Cookie と連動した API キーの状態管理。

### コンポーネント分割 (`src/components/`)

- `TranslationArea`: 入出力のメインエリア。
- `LanguageSwitcher`: 言語選択とスワップ機能。
- `ApiKeyModal`: API キー入力用のモーダル（`httpOnly Cookie` への保存をトリガー）。
- `CharacterCounter`: リアルタイム文字数カウント（5,000 文字制限の視覚化）。

## 5. バックエンド API 設計

### `POST /api/translate`

- **役割**: Cookie から API キーを読み取り、Gemini API へリクエストを投げるプロキシ。
- **セキュリティ**: API キーをフロントエンドに返さない。

### `POST /api/keys`

- **役割**: ユーザーが入力したキーを受け取り、`Set-Cookie: httpOnly; Secure` を発行する。

### `DELETE /api/keys`

- **役割**: Cookie を削除する。
